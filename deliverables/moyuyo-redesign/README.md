# MOYUYO ATELIER · 五 Tab UI 重设计（可交互原型）

## 这是什么

针对以下 5 个 TabBar 页面的 UI 版式与视觉重设计，先出**可交互原型**，代码落地放在下一阶段：

| Tab | 路由 | 原型内容 |
|---|---|---|
| 宠物 | `/` → `pages/tabbar/pet` | 沉浸场景 + 宠物头像条 + 双浮层 + Care Deck + 快捷宫格 |
| 首页 | `pages/tabbar/home` | 顶栏搜索 → 金刚区 → 16:9 Banner → 3 Tab → 两列商品卡 |
| 社区 | `pages/tabbar/community` | 大标题顶栏 → 3 Tab → 搜索 → 话题 chip → 信息流 → FAB |
| 消息 | `pages/tabbar/messages` | 通知聚合 4 格 → 私信会话列表（左滑删除）→ 加载更多 |
| 我的 | `pages/tabbar/user` | 头像 Header → 会员卡 → 钱包 4 格 → 社交 4 格 → 订单 → 功能列表 |

## 怎么看

直接双击 `index.html`（纯静态、零依赖、无外链，可离线打开）。

左侧评审面板提供 5 个开关：**主题**（浅/深/跟随系统）、**尺寸**（390×844 / 430×932 / 375×667）、**状态**（正常/加载/空/错误/未登录/弱网）、**热区标注**、**重置**。

另有一份 `spec.html` —— 设计规范可视化（色板带实测对比度、字号阶梯、圆角/阴影/间距、按钮与卡型、顶栏三变体），用于评审时对照数值，不必翻 Markdown。

## 哪些是真交互

Tab 切换（各页滚动位置重置）· 首页/社区页内 Tab 下划线位移 + 首屏骨架 · 点赞（弹跳 + 计数 + 未登录拦截）· 会话左滑删除（跟手 / 阈值 / 回弹 / 同时只展开一个）· 下拉刷新（阻尼 0.4 / 60px 阈值）· Pet 换宠四联动 · 消息未读链路（进会话 → 未读清除 → 角标 -1 → tabBar 红点同步）· 6 态切换 · 主题切换 · 热区标注。

其余点击进入**占位页**（顶栏返回 + 真实去处标题 + 说明），不是死图。

## 三条已知取舍

1. **图片已接入真实照片**：`assets/photo/` 内 34 张图——29 张取自项目既有素材（`APPdocs/assets/` 的 `product-*` 商品棚拍与场景照），5 张为 AI 生成的补缺品类图（慢食碗 / 猫抓板 / 饮水机 / 外出水壶 / 折叠碗，暖灰底棚拍风格）。接入方式：`data.js` 每个数据点带 `img` 字段 → `art()` 渲染真实图；**图片加载失败时自动回落原色块 + 图标占位**，占位方案完整保留。生成图右下角的"AI 生成"角标已通过 `scale(1.12)` 裁掉；若用于正式物料请注意 AI 生成图的版权口径。
2. **衬线字体不内嵌**：拉丁大字用系统衬线近似，中文标题无衬线 600 + `-0.02em`（Playfair 中文会 fallback 宋体）。
3. **底部 tabBar 是自绘**：生产用 uni-app 原生 tabBar（50px 常量），原型按同尺寸同配色复刻。
