金色（职责拆分）

红线检查清单

原型已逐条通过（浅色 + 深色 + 三档尺寸）。

  • 任意文字与背景对比度 ≥ 4.5:1（大字 ≥ 3:1），金色文字只用 --ink-gold
  • 金色填充上无白字，一律 --on-primary（8.52:1）
  • 所有可点元素热区 ≥ 88×88rpx（原型 5 页审出 0 处例外）
  • 无 #ff4d4f / #007aff / #34c759 / #ff3b30 等非品牌色
  • 无 20rpx 及以下字号承载信息，22rpx 为下限
  • 页面左右边距 = 32rpx（沉浸页除外）
  • 无「白卡 + 1rpx 描边 + 阴影」三重叠加
  • 深色模式下无白色残留块、无不可见文字
  • 无 <svg> / data-URI 占位图，图标只用 luc luc-xxx
  • 衬线字体仅用于拉丁字符，中文标题走 ui 600 + 负字距
  • FAB 距 tabBar = 32rpx（390 / 430 / 375 三档实测 32.0）
  • tabBar 选中色 #DBC98A 与页内 --ink-gold 刻意不一致（勿修）
