# MOYUYO ATELIER · spec ↔ code 差异清单

> **这份东西不是改代码授权。** 它是阶段 3 验收用的对照表，不是第三份规范。
>
> 里面混着两类活儿，性质完全不同，**必须分开对待**：
> - **`纠错`**：代码偏离了已经定稿的口径，但**不改变设计意图**。属 UI 实现范围，前端可直接修，改完回指 02 条款即可。
> - **`行为`**：改完**用户可见行为会变**（多发一个弹窗、少渲染一整块、多一个跳转确认）。**需要主理人或产品点头**，不许以前端自查的名义顺手做。
>
> 不分清这两类，照着清单一把梭，就会变成"用一个 UI 改版的名义做了半个产品改版" —— 这正是主理人裁 F2 时要避免的事。

- **范围**：只收 ① 交互行为 ② 五态 ③ 几何定值 + 语义。**纯视觉 token 替换（颜色/圆角/字号/阴影）不在本表**，那是 01 ↔ 前端线性推进的活，塞进来会让这张表变成"什么都管"，反而没人看。
- **条款号**：一律指 `02-ux-spec.md`，格式 `§3.4` / `CM-10` / `MS-18`。视觉侧条目指 `01-visual-spec.md`。**没有条款号的行不许存在** —— 有它才能改完回指，没它就是第二份规范，会和 02 各自漂移。
- **优先级**：`P0` 必改（影响正确性或 P0 验态）／`P1` 应改（影响体验一致性）／`P2` 建议。
- **复核基线**：`D:/MOYUYOWPC/moyuyo-app/src`，2025-11 当前工作区。行号以本清单落笔时的文件为准；若已漂移，按符号名（`getImageGridClass` / `onLike` / `EMOJI_MAP`）检索，不要盲信行号。
- **版本**：v1.3（`G-01` 目标值补「正文 4 行」前提与按行递减口径，与 01 v1.11 同步）／ v1.2 新增 `G-02b`「页边距/内距/`grid-auto-rows` 必须一次改齐」，`--sab` 已入表 ／ v1.1 并入三项几何裁决 ／ v1.0 初版
