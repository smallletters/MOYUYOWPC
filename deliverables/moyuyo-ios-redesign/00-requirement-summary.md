## A. 五要素需求表

| 维度 | 结论 |
|------|------|
| **场景 Surface** | 移动端（iOS 风格）App 原型，**5 屏**：① `/` 根页（启动入口 · Pet Hub）② `/pages/tabbar/home` 商城首页 ③ `/pages/tabbar/community` 社区信息流 ④ `/pages/tabbar/messages` 消息中心 ⑤ `/pages/tabbar/user` 我的。<br>交付形态：**单文件可交互 HTML 原型**（浏览器直开、5 屏间可跳转、可切状态、可切深浅色），技术底座 uni-app 3 + Vue3 + pinia，同构 H5 + APP 原生两端。 |
| **受众 Audience** | MOYUYO ATELIER 的高端宠物生活方式养宠人群，**iOS 用户为主**，审美要求高、对"廉价感"零容忍。使用场景碎片化：购物前浏览、发帖后看评论、收到提醒后查看，单次停留 30s–3min。设计须同时满足「系统级可信度（像原生 App）」与「品牌贵气（像一本哑光画册）」。 |
| **调性 Tone** | **锁定 iOS HIG 路线**（用户已明确，不走 Editorial Monocle / Brutalist 等其他学派），叠加 MOYUYO 暖调品牌个性。<br>三条不可破的底线：① **金色只做「面」与「线」，绝不做小号文字色**；② **层级靠留白与分组建立，不靠描边堆叠**；③ **一屏一个视觉焦点**，UI 退后、商品图与帖子图上前。<br>明确不要：Material 大圆角浮起卡、iOS 系统蓝、满屏金色铺底、emoji 当图标、通用蓝紫渐变、编造的社会证明。 |
| **品牌上下文 Brand Context** | **完全沿用现有 token**（`src/styles/variables.scss`，浅/深双端已定义完整）：Sand Gold `#DBC98A` / Linen `#F6F2EE` / Charcoal `#2E2B29` / Antique Brass `#B38A5A` / Sage Mist `#ABB9AD` / Dusty Rose `#D9B4B0` / 四产品线色 Care·Gear·Play·Home。<br>图标资产已就绪：`/static/fonts/lucide.ttf`（148 个 lucide 字体图标类，APP/H5 跨端可用）。<br>**新增 token 仅限「职责拆分」型**（ink 文字色族 / on-primary / 暖化 fill / 组件几何量），不得引入第二套品牌色。<br>**真实品牌视觉素材**：11 张已去水印压缩图（见 §B 与附录 3），原型必须使用真实照片而非纯色块占位。 |
| **规模 Scale** | 5 屏单文件交互原型。**主视口 393 × 852 pt（真 iPhone 14 Pro，@3x）**，兼容 390×844 / 430×932 / 375×667 三档。安全区：顶部 59pt（灵动岛机型）、底部 34pt（Home Indicator）。原生 tabBar 高 49pt + 安全区 34pt = 83pt。<br>原型须含：5 屏切换、页内交互、按压态、滚动折叠标题、空/加载/错误/未登录五态、浅/深色切换。 |

**推荐方向（给 Phase 2）**

- **设计系统类型**：**Apple HIG（iOS 17/18）为骨架 + MOYUYO 品牌色板为皮肤**，产出「MOYUYO iOS」专属 token 表 —— 不是"抄 iOS 再换色"，而是「iOS 几何 + 品牌色相 + 暖化中性灰」。
- **建议原型模板**：`mobile-app`（device-frame → status-bar → app-header → app-content → tab-bar）。
- **特别注意事项**：① 现状 `--color-fill`/`--color-fill-dim` 是 iOS **冷灰**（`#F2F2F7`/`#D1D1D6`/`#C7C7CC`），与暖调 Linen 冲突，须暖化；② 现状**金色被当文字色用**，多处实测对比度 1.48–1.65:1，必须做「填充 / 文字墨色」职责拆分；③ 原生 uni-app tabBar **无法施加 backdrop-filter 毛玻璃**，做 iOS 毛玻璃 tabBar 必须自绘（见决策点 C4）。

**素材使用总规则（Phase 3 必读）**

1. **真实照片优先**：所有产品卡 / 帖子图 / Banner 必须用上述真实图片，**禁止**用纯色块或 emoji 占位。
2. **圆角与裁切**：`object-fit: cover` + 卡片圆角；商品图 1:1（700×700 原生即 1:1，无需裁切）；帖子单图 4:5 裁切且 `object-position: center 25%`（保犬脸）。
3. **图片懒加载**：社区信息流图片 `loading="lazy"` + 加载失败回落「暖灰底 + 24px 爪印」占位（现状已有该兜底，保留）。
4. **深色模式**：图片本身不反色；仅图片下方叠加层的文字色切换。
5. **禁止编造**：商品评价文案、销量数字必须用「—」占位或标注灰块，**不得虚构**评价与统计（Anti-Slop P0）。

## C. 关键设计决策点

> 以下 5 项"选哪条都会显著改变最终产出"。每项给 2–3 个候选、各自影响与**我的推荐**（推荐可直接采纳，用户推翻需说明理由）。

### C1 · 品牌强调色策略

| 候选 | 影响 |
|---|---|
| **① 保留 Sand Gold 作系统主色，金色文字改用深化墨色 `#6E5C30`**（推荐） | 品牌辨识度最高。`--ink-gold` 对白 **6.49:1**、对 Linen **5.83:1**，达 WCAG AA；改动集中在 token 层，**不动页面结构**，落地风险最低。风险：金色系偏暖黄，与 iOS 冷调系统感略有张力 —— 但 11 张素材（麦穗、亚麻、黄铜扣）本身全是暖调，走暖路线反而更统一。 |
| ② 保留暖调但**降饱和 + 加深**（如 `#DBC98A` → `#C9B47A` 一类） | 更"高级克制"。但**品牌识别度下降**，且金色已被用于 Logo、IP、包装、渐变，需重做全部品牌资产；且会与 11 张现成暖调素材产生色温漂移。 |
| ③ 全面 iOS 化（系统蓝为主，金色降为装饰点缀） | "像原生 App"最彻底，但 **MOYUYO 品牌资产基本作废**，与"高端宠物生活方式品牌"定位直接冲突，且本轮素材无一适配冷蓝。**不建议**。 |

### C2 · 首页信息架构

| 候选 | 影响 |
|---|---|
| **① Large Title + 吸顶搜索 + 分类 chip 横滑 + 专题卡 + 商品横滑流**（现代 iOS 电商） | 最"iOS 电商"，信息层级最清晰。但**改动最大**：现有 2 列网格 → 横滑流，横滑在小屏一次只看 1.6 张，与现有"一次比较 2 件"的电商心智冲突；且横滑流内放不下 7 张 1:1 商品图 + 完整价格/评分信息。 |
| **② 保留金刚区 4 宫格 + 2 列网格，仅做 iOS 视觉转译**（Large Title + Segmented + 毛玻璃 + 压图 Banner） | **改动最小、风险最低**，业务信息架构完全不动，7 张 1:1 商品图可直接 2×2 满屏，首屏最稳。代价：首屏仍偏"网页感"，决策点里第 4 条问题只解决七成。 |
| **③ 折中：保留金刚区与 2 列网格，但把 4 条产品线（Care/Gear/Play/Home）露出为 chip 横滑**（推荐） | 增加 iOS 电商感又不推翻现有结构；7 张素材恰好**一条产品线一件**，chip 与商品图可一一对应，语义自洽。代价：chip 入口与金刚区「分类」入口**职责重叠**，需明确 chip 跳转目标（建议跳分类页并预选该产品线）。 |

### C3 · 原型形态与交付范围

| 候选 | 影响 |
|---|---|
| **① 带设备框的交互式原型：5 屏可跳转 + 状态切换 + 浅深色 + 触区标注**（推荐） | 评审体验最好，能当场验证折叠标题 / 左滑删除 / 按压态 / 商品网格重排。成本最高（需自绘一套 iOS 组件）。 |
| ② 纯多屏画廊（5 张静态长图并排） | 最快出稿，但**无法验证交互**，与"可交互原型"的目标直接冲突，不满足验收标准 G6。 |
| ③ 交互原型但**不含深色模式 / 不含状态切换** | 中等成本。深色模式是现 token 已支持的能力，放弃等于放弃一次低成本高收益的验证。 |

### C4 · 底部 TabBar 与导航栏的实现路径（工程影响最大）

| 候选 | 影响 |
|---|---|
| **① 原型自绘 iOS 毛玻璃 TabBar，落地阶段同步改自绘 TabBar**（推荐） | 视觉完全达 iOS。**代价**：uni-app 原生 tabBar 被替换，需自绘 tabBar 组件 + 处理 5 页切换与安全区（iOS 端可用原生 blur，Android 降级为半透明纯色）；且 `theme.js syncTabBar()` 的手动同步逻辑可一并删除。 |
| ② 保留原生 tabBar，只调色（`selectedColor` → `#6E5C30`、`borderStyle` → 非 black），原型里也画成非毛玻璃 | 零工程风险，落地最快。**代价**：无法实现毛玻璃与 29pt 图标（原生 iconfont 固定 20px），第 7 条问题只解决一半；且原生 tabBar 的 1px 实线顶边与 iOS hairline 观感不同。 |

### C5 · 深色模式是否纳入本次范围

| 候选 | 影响 |
|---|---|

### A2.4 · 全局交互与动效

- **按压态（补齐）**：可点元素 `transform: scale(.97)` + 背景转 `--color-fill`（iOS 是"变灰"，不是变色），120–150ms，松开 200ms 淡出；列表行按下即变色，**禁 hover**。
- **Large Title 折叠**：`p = clamp(scrollY/52, 0, 1)`；nav 毛玻璃 opacity = p；底 hairline = p × 0.5pt；大标题 opacity = 1 − clamp((p−0.35)/0.5,0,1)、translateY = −12p；居中小标题 opacity = clamp((p−0.55)/0.35,0,1)。**禁**滚动时 nav 高度跳变。
- **动效曲线**：iOS 惯用 `cubic-bezier(.32,.72,0,1)`（250–350ms）；弹跳类 `cubic-bezier(.34,1.56,.64,1)`。
- **降级**：`prefers-reduced-motion` 下禁用粒子与滚动驱动动画，保留状态切换。
- **全局角标规则**：红点 8pt（带 2pt 背景色环）/ 数字角标 h18pt（白字必须 `--color-danger-solid`）；**金色不承担"未读"语义**；tabBar 与 nav 角标样式一致。
