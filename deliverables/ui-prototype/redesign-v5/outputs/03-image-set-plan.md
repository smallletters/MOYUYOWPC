### 1.2 字体阶梯

- **字体族**：无衬线几何体 `-apple-system, "SF Pro Display/Text", "PingFang SC", "Helvetica Neue", sans-serif`；**明确禁衬线**（Logo「MOYUYO」衬线仅作品牌标识，不进界面）。
- **字号阶梯**：34 / 28 / 22 / 20 / 17 / 16 / 15 / 13 / 12 / 11。
  - Large Title 34/700（社区·消息）｜compact nav 标题 17/600｜VIP 数字 28/700
  - 商品名 13/600｜商品描述 11/400（ink-2）｜正文帖文 15/400｜时间/计数 11/400（ink-3 或 tabular-nums）
- **字重**：仅 400 / 600 / 700 三档；数字与金额 `tabular-nums` 等宽；中文不加 letter-spacing > 1px；大标题走紧凑字重对比 + 负字距。

### 1.3 圆角 / 描边 / 阴影 / 材质

- **圆角**：卡片 16 / 大卡·VIP 20 / Banner 18 / 图标底 14 / chip·胶囊 9999 / 头像·FAB 50%。
- **描边**：以 1px 冷灰 hairline `#D6DEE4` 为主分界语言（不用暖色 0.5px，不用刊物全集描边）。
- **阴影**：极轻冷灰漫反射 `0 2px 10px rgba(31,45,61,.06~.10)`；VIP/浮层可到 `.12`；**禁彩色/金色投影、禁高光**。
- **材质**：雾面磨砂、无高光渐变；VIP 卡用同色系明度渐层 `#3A4B5C → #2B3A4A` + 极细砂质噪点（替代旧沙金渐变）。
- **层次顺序**：分组留白 > 冷灰 hairline > 面明度差（雾银底 vs 白卡）> 雾面玻璃 > 极轻阴影（最后手段）。
- **图形语言**：几何线性图标 24×24 / stroke 1.8 / round 端点，仅换色不换形；爪印 `#i-paw` 作低透明空态/占位母题；装饰纹样用极细同心线 / 矿物切片 / 雾面颗粒，**禁放射金光**。
