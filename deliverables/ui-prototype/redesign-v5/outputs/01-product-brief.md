## 0. 一句话结论（给主理人）

MOYUYO = 高端克制的「宠物生活 + 电商 + 社区」App，气质是「哑光精致日常」。用户要的"全新风格"必须同时避开暖沙金（v2/v3）与墨绿刊物风（v4）。**主推「MIST SLATE 雾银石墨 · 静奢矿物」——冷调石墨蓝 + 雾银白 + 干玫瑰点缀 + 无衬线几何体 + 雾面哑光软层次**，是与三版历史色相距离最远、最能凸显真实宠物照片、且静奢感最稳的一套。

## 4. 全新风格定调（本次重点）

### 4.1 历史风格差异坐标（先划清"必须避开"）

| 版本 | 风格代号 | 背景/主色 | 强调色 | 字体语言 | 质感语言 |
|---|---|---|---|---|---|
| v2 | 暖砂哑光 + iOS 分组 | 亚麻暖白 `#F6F2EE` + 沙金 `#DBC98A` | 古铜墨 `#82683A` | SF Pro 无衬线 | 毛玻璃 + 0.5px 发丝 + 极轻暖投影 |
| v3 | 沙金精致强化 | 沙金暖白 | 活力环 / 8折徽章 | SF Pro | 虚化封面 + 更强沙金 |
| v4 | 「墨屿 INK ATELIER · Neo-Editorial」 | 冷白纸底 `#F5F8F7` + 深墨绿 `#125C4E` | 青柠 `#C6F24E` | **衬线刊物大标题** | **零投影 / 1px 描边 / 编辑排版** |
| **v5（本次主推）** | **「MIST SLATE 雾银石墨 · 静奢矿物」** | **雾银白 `#EEF1F3` + 石墨蓝 `#3A4B5C`** | **干玫瑰 `#945048` + 信号红 `#B04A3F`** | **无衬线几何（禁衬线）** | **雾面哑光 + 1px 冷灰描边 + 极轻冷灰漫反射** |

> 结论：v2/v3 是暖黄，v4 是绿+青柠+衬线。主推方向取**冷灰蓝 + 干玫瑰 + 无衬线 + 雾面**，在"色相 / 强调色 / 字体 / 质感"四个维度同时与历史拉开，满足"全新"诉求。

### 4.2 ★ 主推方向：MIST SLATE · 雾银石墨「静奢矿物」

**一句话定位**
> 像一块被雾气打磨过的石墨石板——冷调、沉静、无一处高光；暖色的猫狗照片是石板上唯一的光，UI 只是托住它的底座。

**气质关键词**：冷静 · 精密 · 静奢 · 雾面 · 可信赖 · 秩序。
（延续品牌"高端/克制/哑光"，但把"体温感"从 UI 色彩转移到**照片内容**上——品牌温度由宠物的真实照片承载，UI 保持中性静奢。）

**完整色板（含 HEX，全部经 WCAG 校验，见 §5）**

浅色主题（原型默认）：

**字体策略**
- **无衬线几何体**（明确避开 v4 衬线刊物）：`-apple-system, "SF Pro Display/Text", "PingFang SC", "Helvetica Neue", sans-serif`。
- 大标题走"紧凑字重对比 + 负字距"，不做衬线/刊物编辑感；数字与金额 `tabular-nums` 等宽。
- 沿用 VISUAL_DIRECTION §3.2 的 iOS 字号阶梯（34/28/22/20/17/16/15/13/12/11）与 400/600/700 三档字重；**中文不加 letter-spacing > 1px**。
- Logo「MOYUYO」衬线字**仅保留为品牌标识**（a-brand 摘用），不扩散到界面标题系统——这是与 v4 的关键切割点。

**圆角 / 描边 / 阴影 / 材质语言**
- 圆角：卡片 16 / 大卡·VIP 20 / Banner 18 / 图标底 14 / chip·胶囊 9999 / 头像·FAB 50%（比旧 14 略柔，仍克制）。
- 描边：以 **1px 冷灰 hairline `#D6DEE4`** 为主分界语言（非 v4 的 1px 纯描边全集，也非 v2 的暖色 0.5px）。
- 阴影：**极轻冷灰漫反射** `0 2px 10px rgba(31,45,61,.06~.10)`；VIP/浮层可到 `rgba(31,45,61,.12)`；**禁用彩色/金色投影、禁用高光**。
- 材质：**雾面磨砂、无高光渐变**；VIP 卡用"同色系明度渐层 `#3A4B5C → #2B3A4A` + 极细砂质噪点/雾面颗粒"替代旧沙金渐变，静奢而不失层级。
- 层次顺序：分组留白 > 冷灰 hairline > 面明度差（雾银底 vs 白卡）> 雾面玻璃 > 极轻阴影（最后手段）。

### 4.3 备选方向（供主理人/用户选择，共 3 个）

**备选 A · TERRACOTTA NOIR「陶土夜话」**
- 色板：炭黑底 `#1C1917` / 暖白 `#F3EDE4` / 赤陶 `#C4674A`（点缀文字 `#A9533B`） / 燕麦米 `#E8DDCB`。
- 字体：圆润无衬线（非衬线）；气质：温暖、手作、宠物沙龙感。
- 与历史差异：暖调但**偏红棕陶土**，非沙金的黄；比 v4 暖且无青柠。
- 取舍：温度感最强，但"高端静奢"略弱于主推，且与暖色照片同色系、照片不够跳。

**备选 B · INDIGO VELLUM「靛蓝植绒」**
- 色板：午夜靛蓝 `#1E2A44`（主/深底） / 暖象牙 `#F4EFE4`（浅底） / 香槟银 `#C9BFA8`（细描边） / 灰蓝 `#6E7FA8`。
- 字体：无衬线 + 小字号宽字距标签（雅致）；气质：静奢、夜色、丝绒植绒哑光。
- 与历史差异：蓝紫调，完全避开暖金与墨绿。
- 取舍：夜间质感极佳，但浅色态偏少、白天信息密度场景（商城/社区）可读性不如主推。

**备选 C · WABI PAPER「侘寂生纸」**
- 色板：生纸米白 `#EFEDE6` / 炭黑 `#2B2B2B` / 单一朱红点缀 `#B23A2E`。
- 字体：无衬线 + 大留白 + 细线框；气质：日式侘寂、极简、禅意空白。
- 与历史差异：无彩极简 + 单点朱红，与 v4 的"衬线刊物编辑排版"是两种东西（侘寂留白 vs 刊物排版）。
- 取舍：最克制高级，但电商信息密度下"留白奢侈"会牺牲商品承载量，适合做概念版而非全量落地。

### 4.4 为什么主推 MIST SLATE（推荐理由）

1. **"全新"最稳**：在色相（冷蓝 vs 暖黄/墨绿）、强调色（干玫瑰 vs 沙金/青柠）、字体（无衬线 vs 衬线刊物）、质感（雾面软层次 vs 暖毛玻璃/零描边）四维同时区别于 v2/v3/v4，最不容易被误认成旧版。
2. **品牌调性最贴**：冷静石墨蓝 + 雾面哑光 + 1px 冷灰线 = 高端克制；无高光、无彩色投影，延续品牌"哑光红线"；静奢感比陶土/侘寂更稳重可信，契合"注重品质的宠物主"。
3. **让真实素材当主角**：32 张暖色猫狗/产品照在冷灰蓝底上自然成为唯一暖色焦点，UI 退后——正是 VISUAL_DIRECTION「社区 UGC 图片才是视觉主角，UI 必须退后」的最佳实现；陶土/靛蓝方案会与照片抢色或压暗照片。
4. **工程与可访问性友好**：灰蓝同色系易做深浅两态；强调色分工清晰（品牌=石墨蓝、点缀=干玫瑰、信号=红），色弱下靠字重/形状/位置双重编码也成立；各关键组合已过 WCAG（见 §5）。

### 5.3 可读性红线（写入下游验收）

1. 品牌主色石墨蓝 `#3A4B5C` 可安全做文字/标签（≥4.5），但**雾银底 `#EEF1F3` 上不得用低于 `#566573` 的文字承载正文**。

5. `prefers-reduced-motion` 降级、44×44 触控热区、tabular-nums 数字等沿用 UX_SPEC §5，新风格不降低原有可访问性基线。
