## 0. 项目背景
- MOYUYO 是一个「宠物生活 + 电商 + 社区」的 uni-app 3 / Vue3 跨端 App（H5 + APP 原生），当前 dev server 在 `http://192.168.64.103:5174`。
- 本次任务：**重新设计 4 个 tabBar 页面的 UI 布局样式，先产出 iOS 风格的可交互原型**（原型阶段不接真实后端，用静态仿真数据即可）。
- 目标形态：单一自包含 HTML 原型，浏览器直接打开，模拟 iPhone 外壳 + 底部 tabBar 切换 4 个页面，可点击交互。

## 3. 四个页面现状（实证结构，供重设计参考，勿遗漏核心功能）

### 3.1 首页 home（src/pages/tabbar/home.vue）
- 顶部：sticky 自定义导航栏 = 搜索胶囊（放大镜 + 占位文案）+ 扫码图标 + 铃铛图标（未读数字角标）
- 金刚区：4 宫格入口（分类/会员/领券/限时），圆角方块图标 + 文字
- Banner：CMS 轮播，16:9 圆角卡片，支持标题浮层 + tag；有纯色兜底
- 推荐区：3 tab（猜你喜欢 / 今日爆款 / 口碑好评），2 列商品卡片网格（1:1 图 + 名称 + 描述 + 现价/划线原价 + 评分星）
- 交互：搜索/扫码/通知/金刚区跳转、banner 点击、推荐切 tab、商品详情、下拉刷新、触底加载

### 3.2 社区 community（src/pages/tabbar/community.vue）
- 顶部：大标题「社区」+ 搜索图标 + 铃铛图标（红点）
- Tab：推荐 / 关注 / 话题（下划线指示）
- 推荐 tab 下：胶囊搜索条 + 话题标签横向滚动 chips（#话题）
- 信息流：帖子卡片 = 作者头像/昵称/时间 + 更多按钮 + 图片（单大图/九宫格）+ 正文 + 互动行（点赞/评论/分享）
- 右下浮动发布按钮 FAB（相机图标）
- 交互：切 tab、话题点击、点赞（未登录拦截）、评论、分享（复制链接）、更多（删除/不感兴趣/举报）、发帖、进作者主页、下拉刷新、触底加载

### 3.3 消息 messages（src/pages/tabbar/messages.vue）
- 顶部：标题「消息」+ 铃铛（未读数角标）+ 发起群聊 + 发起私信
- 未登录：登录引导卡片
- 已登录：
  - 通知聚合卡：4 宫格（全部/互动/订单/系统）圆形图标 + 红点
  - 私信区块：标题 + 未读 badge + 「发起私信」操作
  - 会话列表：头像 + 名称（置顶图标）+ 时间 + 消息摘要 + 未读角标；支持左滑删除、长按置顶/删除；含客服会话（耳机图标）
  - 空态、分页加载
- 交互：通知入口、发起私信/群聊、会话点击、左滑删除、长按菜单、登录

### 3.4 我的 user（src/pages/tabbar/user.vue）
- 顶部（白底大 header）：用户头像 + 昵称/邮箱 + 会员等级；未登录显示登录引导
- VIP 会员卡：渐变卡片（沙金渐变）+ 标题 + Points + 提示 + 箭头，点击进入会员中心
- 钱包区：4 宫格（浏览足迹/积分/优惠券/收藏），数字 + 标签
- 社交宫格（social-grid）：关注/粉丝/收藏/个人中心，数字 + 标签 + 图标徽章
- 订单宫格：卡片标题「我的订单」+ 查看全部 + 4 图标（待付款/购物车/待收货/待评价）+ 角标
- 功能列表：11 项竖直列表（签到/任务/邀请/会员/地址/宠物/收藏/足迹/帮助/设置/关于），左图标 + 文案 + 右箭头
- 页脚：品牌 slogan
- 交互：进个人资料、会员中心、各宫格跳转、功能列表跳转、下拉刷新

## 4. 关键约束
- 品牌气质：高端、克制、哑光沙金 + 亚麻暖白，走「精致生活」路线，不要廉价高饱和。
- iOS 风格目标：遵循 iOS 17/18 HIG——大标题 Large Title、分组圆角卡片（inset grouped）、毛玻璃导航栏与 tabBar、系统蓝/品牌色强调、清晰的字号层级、SF Pro 风格字体栈、恰当的分隔线与留白、安全区适配（灵动岛/刘海 + Home Indicator）。
- 原型要求：4 页可 tab 切换；关键控件可点击反馈（如点赞变色、tab 切换、弹层、深浅色切换可选）；滚动流畅；静态数据仿真但内容真实（用上面列出的真实功能与文案方向）。
- 不要引入外部 CDN 依赖（离线可打开）；图标可用内联 SVG 或纯 CSS/emoji 实现，但需精致统一。
