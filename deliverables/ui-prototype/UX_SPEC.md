## 0. 三个开放项的最终结论（先给结论，不阻塞）

| # | 开放项 | 结论 | 一句话理由 |
|---|---|---|---|
| 1 | tabBar 顺序 | **重排为 `首页 / 社区 / 宠物 / 消息 / 我的`**；首页为默认选中项（落地页） | 首页是 iOS 默认落地页必须居首、「我的」恒在最右，宠物作为核心域占位居中不破坏动线。 |
| 2 | 我的页 11 项列表 | **拆 3 组**（常用 / 账户与服务 / 关于） | 单组 11 行超出舒适扫描长度（单组宜 5–7 行），分组降低长列表疲劳并提升定位效率。 |
| 3a | 首页推荐区 section 标题 | **不保留**独立 section 标题，3 个 tab 标签本身即区块标识 | 「猜你喜欢」等 tab 已承担分类告知，再加同名标题语义重复且吃掉首屏约 34px 垂直空间。 |
| 3b | 社区「话题」tab | **保留**话题 tab（推荐 / 关注 / 话题 三段不变） | 话题是区别于算法流、好友流的独立内容聚合心智，推荐流里的话题 chip 只是筛选，不能替代话题聚合页。 |

> 顺序落地提示（给 Phase 3）：默认高亮「首页」；「宠物」tab 仅渲染占位图标 + 中性占位文案（如「宠物 · 敬请期待」），点击给 toast，不做真实页面，但保留 tab 位与切换能力。

## 2. iOS 原生交互范式映射（逐页）

| 页面 | 采用的 iOS HIG 模式 | 落地要点（对齐 VISUAL_DIRECTION） |
|---|---|---|
| **全局** | Large Title 折叠、inset grouped、毛玻璃 nav/tabBar、Home Indicator、status bar 主题适配、tab 瞬切、sheet / context menu / swipe actions | tabBar 切换为**瞬切 + 交叉淡入**（无 Material 滑动页动画）；所有卡片用 grouped 圆角 14 + 0.5px hairline；弹层统一 `translateY(100%→0)` 420ms `--ease-ios-sheet`。 |
| **首页** | Compact nav（搜索胶囊内嵌工具条）、sticky 文字 tab（类 segmented，用下划线而非胶囊）、Featuring 分页轮播、search field 变体、UIRefreshControl | 推荐 3 tab 属**内容流分层**，用下划线指示条（比 iOS 胶囊 segmented 更适配电商信息密度），指示条 220ms 位移；Banner 为自动分页（3000ms/500ms ease-in-out），指示点跟随；商品卡**无 hover 抬升**，仅按下 `scale(.985)` 150ms。 |
| **社区** | Large Title + 工具条图标、分段 tab、search bar、**FAB 的 iOS 取舍**、点赞 spring、action sheet（评论/分享/更多）、context menu | FAB 取舍见下方 §2.1；点赞心形 spring `1→1.28→.92→1`，计数 120ms 淡入；评论/分享/更多均用**模态 sheet**（非新页），符合 iOS 模态范式；话题 chip 横滚隐藏滚动条。 |
| **消息** | Large Title + 工具条、inset grouped 宫格、**swipe actions（左滑删除）**、context menu（长按）、unread badge、empty state | 左滑**跟手无 transition**，露出 80px 红底白字「删除」，**40px 阈值吸附**，超出阻尼 `80+(delta-80)*.2`，松手 spring 250ms；会话已打开时点击行**先关闭滑出**再进会话；客服会话禁用左滑删除。 |
| **我的** | 透明 nav → 滚动毛玻璃、inset grouped 分组列表、UISwitch（主题，见 §3.4）、chevron 行、自定义 VIP 卡 | 透明 nav 叠在 header 上，滚动后浮 46 居中标题；功能列表 3 组各用独立 card；行按下即变色（`:active` 无过渡，松开 200ms 淡出）。 |

### 2.1 社区 FAB 的 iOS 取舍（明确结论）
**结论：保留右下 FAB，但用 iOS 模态 sheet 承载撰写（不做新页面跳转）。**
理由：
1. 纯 iOS HIG 确实不内置 FAB（那是 Material 概念），但「发布」是社区最高频核心动作，右下 thumb zone 可达性最优；Instagram / X 的 iOS 版均已采用右下撰写按钮，成为信息流场景的事实标准。
2. 视觉规范 §5.4 已完整定义 FAB 样式与下滑淡出动效，保留可保持视觉契约一致，改动成本最低。
3. iOS 化折中：点击 FAB **不 push 新页**，而是从底部弹起撰写 sheet（iOS 模态），关闭手势/取消按钮符合 HIG；这样兼顾拇指可达性与 iOS 模态范式。
> 备选（若 team-lead 坚持纯 HIG）：改为 nav 右上角「撰写」文字按钮，代价是发布动作可达性下降、与社区信息流习惯相悖。**本次原型采用保留 FAB 方案。**

## 4. 关键用户流程（点击路径）

**流程 A · 逛首页 → 看商品**
`打开 App（默认首页）→ 点推荐 tab「今日爆款」→ 指示条滑动、卡片切换 → 点某商品卡（scale 按压）→ toast「商品详情」`
（Banner 自动轮播并行发生，指示点同步）

**流程 B · 社区互动 → 点赞 → 评论**
`点 tab「社区」→ 点 tab「推荐」→ 点话题 chip「#萌宠日常」（chip 选中、流筛选）→ 点某帖「点赞」（心形填充+计数+1）→ 点「评论」（弹起评论 sheet）→ 点遮罩关闭`

**流程 C · 消息 → 左滑删除会话**
`点 tab「消息」→（未登录先点登录卡）→ 在会话行上左滑跟手 → 露出红底「删除」→ 松手 ≥40px 吸附全开 → 点「删除」→ 行收拢、列表上移`

**流程 D · 我的 → 切换深色主题**
`点 tab「我的」→ 点 nav 右上主题按钮 → html.theme-dark 生效、全页换肤 → toast「已切换至深色」→ 切回其他 tab 验证主题全局一致`

## 5. 可访问性与空态 / 加载态 / 错误态

### 5.1 可访问性（a11y）
| 项 | 要求（原型阶段可落地部分） |
|---|---|
| 触控热区 | 所有可点元素 **≥44×44pt**：nav 工具图标 44×44、帖子「更多」hit 44×44（视觉 22）、FAB 56；tabBar item 高 49 宽 78.6 达标；列表行高 ≥52。 |
| 对比度 | 严格遵循 VISUAL_DIRECTION §2.4：正文 `--label` 12.63:1、次级 `--label-2` 4.88:1；**沙金 `#DBC98A` 不做文字**；选中标签用 `#82683A`(4.72:1)、选中图标 `#B38A5A`(3.13:1)。 |
| 色弱友好 | 点赞态不仅靠红色：心形由**描边→实心**形状变化 + 计数递增双重编码；未读靠角标数字/红点 + 位置，不单靠色相。 |
| 读屏语义 | 交互控件加 `aria-label`（如「点赞」「删除会话」「切换深色模式」）；tab 用 `role="tab"` + `aria-selected`；弹层加 `role="dialog"` + 关闭按钮。 |
| 动效降级 | `@media (prefers-reduced-motion: reduce)` 生效（VISUAL_DIRECTION §7.3），所有动画/过渡降为 .01ms。 |
| 键盘可达 | 原型主路径支持 Tab 聚焦 + Enter 触发（可选增强，P1）。 |

### 5.2 三态在原型中的呈现
| 态 | 呈现方式（原型统一约定） |
|---|---|
| **加载态** | 列表区显示 3–4 个骨架占位块（`--fill-2` 灰块，圆角同卡片，轻微呼吸动画）；原型可用 `setTimeout 400ms` 模拟骨架→内容切换（P1）。 |
| **空态** | 居中插画（低透明度爪印 64px）+ 主文案 15/600 `--label` + 副文案 13 `--label-3` + 可选操作按钮；消息无会话、社区关注流无内容、搜索无结果均用此样式。 |
| **错误态 / 未登录** | 未登录统一用**引导卡**（图标 + 说明 + 主 CTA 沙金按钮）；网络错误用内联提示条（warn 色 + 重试按钮）。原型以未登录引导为主（消息页必须可见）。 |
| **反馈 toast** | 所有「点击后无真实跳转」的入口统一 toast：底部居中、深色胶囊、白字 14、2s 自动消失；避免用户误认为点击无效。 |
