## BugFix：APP 端头像不显示（moyuyo-app）

- **现象**：APP 真机 `/pages/tabbar/user`、`/pages/community/profile` 头像空白；H5 端三处正常；APP 端 `/pages/tabbar/community` 正常。
- **根因**：`src/utils/imageUrl.js` 的 `toAbsoluteImageUrl()` 使用了运行时守卫
  `(typeof process !== 'undefined' && process.env && process.env.VITE_ADMIN_API_BASE) || ''`。
  Vite `define` 只能在**编译期**替换静态表达式 `process.env.VITE_ADMIN_API_BASE`，而 `typeof process !== 'undefined'` 是运行时求值；uni-app APP 端 `typeof process === 'undefined'` → `&&` 链短路 → base 恒为空 → 后端返回的相对路径 `/uploads/...` 未拼成绝对 URL → 原生 `<image>` 加载失败 → 空白。
  H5 端 process 存在故正常；`tabbar/community.vue:502` 绕开了该函数（裸读 base）故正常。
- **修复**：`src/utils/imageUrl.js:27` 改为裸读 `const base = process.env.VITE_ADMIN_API_BASE || ''`，与 `request.js:239`、`tabbar/community.vue:502`、`api/cms.js` 的既有约定一致。**仅 1 个文件、最小变更**，函数其余分支与签名未动。
