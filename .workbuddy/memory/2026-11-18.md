### 图标显示修复（用户 11-19 追加）
- 诊断：file:// 与 HTTP 预览两环境下图标字体均正常（fonts.check true、24 类 0 缺失 glyph、预览服务返回 200 font/ttf），页面实际渲染无豆腐块。用户所报"图标没有显示"按两种可能双修：
- ① **字体兜底加固**：`assets/lucide.css` 的 @font-face 改为 base64 data URI 内联（51KB，保留 url('lucide.ttf') 为第二源）——任何环境不再依赖 .ttf 文件加载，杜绝 MIME/CORS/路径导致的图标空白。
- ② **Pet 头像条换真实照片**：pets 数据加 img（Luna→s-dog2 / Momo→s-cat / Coco→s-dog / Nori→s-cat2），petStrip 渲染 `<img class="pet-ava__img">`，onerror 回落品种图标；添加按钮保留 + 号。这是全原型最后一个"图标充当占位"的显眼位置。
- 经验：用户报"X 没显示"时，先复现两个环境（file:// + 预览 HTTP），确认技术侧正常后再按语义推测诉求，两个最可能解读都修掉并明确告知。
